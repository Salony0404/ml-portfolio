# Insurance Premium Prediction

## Overview
This project focuses on analyzing an insurance dataset and building machine learning models to understand the factors that influence insurance premiums. The work is implemented using Python and documented in a Jupyter Notebook, following a standard data science workflow.

---

## Problem Statement
Insurance companies determine premiums based on several personal and health-related attributes.  
The goal of this project is to explore the dataset, perform feature engineering, and apply machine learning models to predict insurance charges accurately.

---

## Dataset
The dataset contains information such as:
- Age
- Sex
- BMI
- Number of children
- Smoking status
- Region
- Insurance charges

The dataset is used solely for educational and learning purposes.

---

## Approach
The project follows these steps:
1. Data loading and cleaning
2. Exploratory Data Analysis (EDA)
3. Feature encoding and preprocessing
4. Model training using machine learning algorithms
5. Model evaluation using appropriate metrics

---

## Models Used
- Linear Regression  
- Other regression models (if applicable)

---

## Results
The trained models demonstrate how demographic and lifestyle factors impact insurance premiums.  
Performance is evaluated using standard regression metrics such as R² score and Mean Squared Error.
