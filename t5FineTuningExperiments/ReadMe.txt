# T5 Fine-Tuning Experiments

## Overview
This project contains experiments for fine-tuning the T5 family of sequence-to-sequence models on a custom dataset. The notebooks explore data preprocessing, tokenization, training, inference, and evaluation (ROUGE/qualitative).

---

## Goals
- Fine-tune T5 for the target task (e.g., summarization / code explanation)
- Evaluate model outputs using ROUGE and qualitative inspection
- Compare multiple training runs and hyperparameters
