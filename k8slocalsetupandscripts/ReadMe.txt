Kubernetes Local Setup with Minikube, kubectl, and Helm

Overview
This project documents and automates the local Kubernetes environment setup using Minikube,kubectl, and Helm.  
It is designed to help users quickly create a local Kubernetes cluster, manage deployments, and work with Helm charts in a reproducible way.

This repository focuses on setup scripts, references, and configuration, rather than committing large binary installers.

---

Tools Used
- Kubernetes (kubectl)– command-line tool to interact with clusters
- Minikube – local Kubernetes cluster
- Helm – Kubernetes package manager
- Docker– container runtime used by Minikube
